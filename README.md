# Bijoux Accessoire — Mobile First Demo

هذه النسخة HTML/CSS/JS تعمل مباشرة بدون Next.js أو npm.

## تشغيل
افتح `index.html` مباشرة أو ارفع محتويات المجلد إلى أي استضافة Static.

## لوحة الإدارة
الرابط: `admin-login.html`
كلمة المرور التجريبية: `123456`

## مهم
هذه النسخة تستخدم localStorage حتى تعمل فورًا كنسخة تجريبية. المنتجات والطلبات المحفوظة بهذه الطريقة تظهر على نفس المتصفح/الجهاز فقط.
للاستخدام الحقيقي مع عملاء متعددين، يجب ربطها بـ Supabase أو Backend آمن، وكذلك استبدال تسجيل دخول Admin التجريبي بمصادقة حقيقية.
