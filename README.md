# Bijoux Accessoire — Vercel Ready Demo

نسخة Static تعمل مباشرة على GitHub Pages أو Vercel بدون npm أو build.

## الصفحات
- `/` — المتجر
- `/checkout.html` — السلة وتأكيد الطلب
- `/admin` — تسجيل دخول الإدارة
- `/admin/dashboard` — لوحة الإدارة بعد تسجيل الدخول

## كلمة المرور التجريبية
`2003`

يمكن تغييرها من داخل لوحة الإدارة. **هذه مصادقة تجريبية فقط** لأن كلمة المرور محفوظة في `localStorage`، وليست حماية حقيقية لخادم.

## ما تم إصلاحه
- تهيئة المنتجات التجريبية تلقائيًا حتى تظهر في المتجر ولوحة الإدارة.
- حماية قراءة `localStorage` من JSON تالف حتى لا يتوقف JavaScript.
- منع إضافة كمية أكبر من المخزون.
- منع زيادة كمية السلة فوق المخزون في صفحة الطلب.
- تحسين التعامل مع البيانات الناقصة في لوحة الإدارة.
- الحفاظ على الصور المرفوعة وروابط الصور.
- الحفاظ على مسارات Vercel `/admin` و`/admin/dashboard`.

## مهم قبل الاستخدام الحقيقي
هذه النسخة تعتمد على `localStorage`. لذلك الطلبات والمنتجات **لا تنتقل بين أجهزة العملاء ولوحة الإدارة**؛ كل جهاز لديه بياناته الخاصة.
إذا كان الهدف أن يرسل أي زبون طلبًا ويظهر فورًا عندك في لوحة الإدارة، يجب ربط المشروع بقاعدة بيانات/Backend مثل Supabase، مع مصادقة Admin حقيقية.
